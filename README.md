# GRC Tools

Small, independent tools for **Governance, Risk & Compliance (GRC)** and **third-party risk management (TPRM)**, built in the open to learn the field by doing.

> **Status: in constant development, for professional education.**
> These tools are learning projects. They use public data, they have known limitations (each README lists them), and they are not a substitute for a commercial product or for professional advice. Expect things to change often.

## Tools

| Tool | What it answers | Status |
|---|---|---|
| [Subprocessor Watch](tools/subprocessor-watch/) · **[open the page](https://juanbracho.github.io/GRC-Tools/subprocessor-watch/)** | Who do my vendors send data to, what changed, and which of those companies had a security incident? | v0.1, runs daily |

More tools will be added one at a time. Each one lives in its own folder with its own README, tests and data, so it can stand alone.

## Principles
- **Public data only.** No login walls, respect for `robots.txt`, one polite visit per day.
- **Every fact has a source and a date.** If you can't click through to verify it, it doesn't belong here.
- **Leads, not verdicts.** Automated findings are prompts for a human to review.
- **Honest limits.** Each README says what the tool can't do and what commercial tools do better.
